      04 / 技术说明

      为什么这样搭

      完整版见 TECHNICAL-NOTE.md

      端侧推理

      Transformers.js + ONNX Runtime Web 在浏览器内执行 BGE 模型。优先请求 WebGPU；不可用或初始化失败时自动改用 WASM，并在右上角明确显示当前后端。

      存进 seekdb

      集合使用 ngram 全文索引与 HNSW 余弦向量索引。浏览器只提交向量与原文，入库、索引刷新与检索都在本地 seekdb 中完成。

      混合检索

      collection.hybridSearch() 调用 seekdb 的 DBMS_HYBRID_SEARCH，在一次调用里完成全文与向量召回，并用 RRF 融合；客户端不做二次拼合。

      增量与状态

      同一文档再次导入时先按 doc_id 删除旧片段再写入，随后调用 dbms_index_manager.refresh()，确保新内容立即可检索；知识库切换状态持久化在本地。
